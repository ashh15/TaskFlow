# MERN TaskFlow

A full-stack Task Tracking application built with React, Node.js, Express, and MongoDB.

## Features

- User Authentication using JWT
- Login & Signup
- Add Tasks
- Update Tasks
- Delete Tasks
- Delete Multiple Tasks
- User-specific Tasks
- Priority levels
- Status tracking
- Due dates
- Protected Routes

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
